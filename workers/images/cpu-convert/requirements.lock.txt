# Pinned, hash-free lock for the cpu-convert worker image: backs every Convert-tab op
# (c_onnx, c_tflite, c_torchscript, c_savedmodel, c_safetensors, c_openvino) except
# TensorRT and Core ML, per `packages/catalog/src/modelforge_catalog/converts.py`'s
# `worker_image="cpu-convert"` on those six OperationSpecs. A single combined image is
# used (instead of splitting across cpu-torch/cpu-tf) because several of these ops need
# both frameworks within one job — e.g. c_tflite's torch-sourced... actually no torch-
# sourced chain is implemented (see workers/ops/convert_tflite.py's docstring for why), but
# c_tflite's `onnx`/`keras` casters need TensorFlow while its `yolo` caster needs PyTorch +
# Ultralytics, and a single `OperationSpec` can only declare one `worker_image`.
#
# Generated from a real resolved install (`pip install -e workers[torch-ops,tf-ops,
# convert-ops] ultralytics transformers pycocotools`, plus `tf_keras` — needed by
# onnx2tf's `tflite_backend="tf_converter"` SavedModel output path, see
# workers/ops/convert_savedmodel.py's docstring) on 2026-10-18; regenerate with the same
# command in a clean venv whenever a version here needs bumping, rather than hand-editing
# one line at a time.
#
# `tf_keras` declares a dependency on the full `tensorflow` PyPI package
# (`tensorflow<2.22,>=2.21`), not `tensorflow_cpu`. Tried dropping the separate
# `tensorflow` wheel and keeping only `tensorflow_cpu` (consistent with the `tf-ops`
# extra's `sys_platform` split) — that broke the import outright
# (`AttributeError: module 'tensorflow' has no attribute '__version__'`, confirmed by
# actually uninstalling `tensorflow` in this venv and reproducing it), so both packages
# are pinned here; this roughly doubles this image's TensorFlow footprint versus
# `cpu-tf`'s `tensorflow_cpu`-only install, which is the real cost of onnx2tf's
# SavedModel output path (`tflite_backend="tf_converter"`) needing `tf_keras`.
#
# torch comes from the CPU-only wheel index — build with:
#   pip install -r requirements.lock.txt --extra-index-url https://download.pytorch.org/whl/cpu
